# ADR-005：分叉采用客户端重放模拟

- Status: Accepted
- Date: 2026-11-14

## Context

网页版不提供服务端分叉。用户希望在不影响原会话的情况下探索不同路径。

## Decision

读取父会话该轮之前的全部消息，创建新会话并按序重放；原会话不变。附件不可重放，必须在 UI 明示。

## Consequences

- 分叉是客户端模拟，不是服务端语义分叉。
- 附件缺失需提示；失败可重试、可取消。
- 需要记录 `Fork` 关系便于查看。

## Alternatives considered

- 重新编辑提问：切换成本高，体验差。
- 服务端分叉：网页版不提供，否决。
