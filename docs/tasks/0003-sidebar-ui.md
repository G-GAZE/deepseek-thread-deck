# 任务 0003：侧边栏 UI（P0 阶段 7）

> 状态：进行中。上游：任务 0001 §5（侧边栏项目树 / 搜索框 / 命中跳转）、任务 0002 阶段 5.5（索引持久化）。
> 交付格式见 AGENTS.md §6；风险与实测见交付卡。

## 范围（必须完成）

1. content script 用 **shadow DOM** 挂右侧浮动面板（可折叠），**不注入页面业务区域**。
2. 面板：项目树（项目 + 会话计数 + 未分类）、搜索框、结果列表、索引/同步状态条。
3. 数据只经 core API：`openDeckDatabase` / `createProjectStore` / `createSearchIndex` / `createConversationSync`（当前无可用 `RemoteSource`，同步按钮置灰并提示「等待页面适配」）。
4. 项目 CRUD 最小集：新建、重命名、删除、把会话分配到项目 / 退回未分类。
5. 首建索引进度（读 `deck.search.indexProgress.v1`），就绪前搜索走标题兜底并提示。
6. 状态兜底：空库 / DB 打开失败 / flag 关闭 / 选择器未适配（适配中）均不崩溃。

## 不做

- 不改 DeepSeek DOM、不猜选择器、不拦截请求。
- 不做注入、分叉、导出、相似提醒。
- 不做拖拽动画、主题定制、多语言。

## 验收

- 面板可折叠，开合不影响页面滚动与输入框。
- 项目树计数与 core 一致（含未分类），CRUD 后即时刷新。
- 搜索防抖 200ms，显示标题 + 摘要；空结果、空库不报错。
- 首建显示 `N%` 进度；就绪前搜索走标题兜底并提示。
- DB 打开失败 / flag 关闭 / 选择器未适配均不崩溃。

## UNSURE

- **命中跳转**依赖 `src/shared/selectors.ts`（当前全空）。本阶段先做「复制会话 id + 提示待适配」，真实滚动跳转待实测选择器后另开任务（open-questions Q12）。
